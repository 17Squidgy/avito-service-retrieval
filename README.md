# Авито: кандидатогенерация услуг, Recall@50

По каждому запросу решение выбирает 50 объявлений из `benchmark_items.parquet`.
Итоговая модель: **несколько поисковых генераторов + E5-small + CatBoostClassifier**.
Описание данных, признаков, проверки качества и ошибок: [SOLUTION.md](SOLUTION.md).

| Проверка | Результат |
|---|---:|
| Development Recall@50 итоговой модели | 0.858490 |
| Development Recall@50 исходной HGB | 0.855333 |
| Полнота объединённого пула итоговой модели | 0.957167 |
| Итоговый CSV | 2 452 строки, по 50 уникальных item_id |

Это локальная проверка, не лидерборд. Небольшой прирост CatBoost статистически
неубедителен. Старый результат 0.8444 на отложенном тесте относится **только к
исходной HGB**: итоговый CatBoost на этом тесте не оценивался.

## Воспроизведение answer.csv

Запускайте команды из корня репозитория. Проверенное окружение: Python 3.14,
macOS ARM, Apple M4 Pro / MPS, 48 ГБ RAM. Точные версии зависимостей зафиксированы.
Для первого запуска нужны интернет, `curl` и место для данных/весов/индексов;
сама модель работает локально, без внешних API. На CPU выполнение поддерживается,
но первоначальное вычисление эмбеддингов значительно медленнее.

```bash
python3.14 -m venv .venv
.venv/bin/pip install -r requirements-lock.txt
.venv/bin/pip install -e . --no-deps --no-build-isolation
.venv/bin/python scripts/download_data.py
.venv/bin/python scripts/download_model.py
.venv/bin/python scripts/reproduce.py
```

`download_data.py` получает три исходных Parquet из публичного архива организатора
и проверяет SHA-256 архива. Если данные уже получены, положите их в `data/raw/`.
`download_model.py` скачивает E5 по фиксированной ревизии. Затем `reproduce.py`:

1. Загружает включённый в репозиторий `model/selector.cbm` и проверяет его хеш.
2. Заново строит индексы и статистики из исходных данных, получает кандидатов,
   вычисляет признаки и применяет замороженную модель. Готовые ответы не читает.
3. Проверяет формат и принадлежность ID корпусу; записывает `answer.csv`.
4. Сравнивает SHA-256 результата с зафиксированным в `model/manifest.json`.

Ожидаемый SHA-256 файла:

```text
39293118374a94e4473bf3caf74f023b77642cc943b27c529d2942bd1bc8d22e
```

Эмбеддинги кешируются по содержимому, а не по ответам или query_id. Повторный
запуск использует кеш для ускорения. Численные различия между CPU/CUDA/MPS и
версиями библиотек могут изменить пограничные кандидаты или порядок ID; проверка
хеша в таком случае явно завершится ошибкой. Байтовая идентичность не заявляется
для непроверенных аппаратных конфигураций. Порядок ID не влияет на Recall@50,
но проверка хеша намеренно строже метрики.

Файл модели занимает менее 1 МБ и включён в репозиторий в нативном формате
CatBoost; для воспроизведения ответа не нужны исключённые из Git `.joblib` файлы,
экспериментальные кеши, HyDE или повторное обучение.

## Повторное обучение и эксперименты

Для переобучения выбранной конфигурации после установки и загрузки данных/весов:

```bash
.venv/bin/python scripts/build_larger_pool.py
.venv/bin/python -m avito_retrieval.catboost_experiment \
  --cache artifacts/pool300/validation_candidates.joblib \
  --enhanced --kinds classifier --threads 4 --output artifacts/retrained
```

Обучение выполняется на CPU с фиксированным seed. Сохраняются контрольные точки
и выбранная по development модель; по результатам проведённого эксперимента это
350 деревьев. Переобучение — исследовательский режим; воспроизведение отправленного
файла использует включённые замороженные веса через `scripts/reproduce.py`.

Полная история подходов: [EXPERIMENTS.md](EXPERIMENTS.md).
Команды и таблица CatBoost/HyDE: [отчёт второго этапа](reports/round2/README.md).
Результаты выбора модели: [comparison.json](reports/round2/comparison.json).

## Структура

| Путь | Назначение |
|---|---|
| `src/avito_retrieval/data.py` | Чтение данных, нормализация, разбиение без пересечения контекстов |
| `retrieval.py`, `dense.py` в этом же пакете | Лексические, исторические, географические и нейросетевые генераторы |
| `features.py`, `catboost_experiment.py` | Дополнительные признаки и обучение селектора |
| `catboost_predict.py`, `submission.py` | Предсказание и строгая проверка CSV |
| `model/` | Замороженные веса, схема признаков, контрольные суммы |
| `scripts/` | Загрузка, воспроизведение, анализ ошибок, эксперименты |
| `tests/` | Контракты разбиения, признаков, метрики и формата |
| `reports/` | Измеренные результаты и анализ ошибок |

```bash
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m avito_retrieval.submission answer.csv
```

Данные, большие веса E5, окружение, кеши, логи и CSV не включаются в Git;
они восстанавливаются командами выше. Используемые открытые модели и библиотеки
перечислены в [THIRD_PARTY.md](THIRD_PARTY.md).

на платформу выполняются отдельно; код не расходует официальные попытки.
